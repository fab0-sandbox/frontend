# Spec 15: Greet a visitor by name (frontend)

## Scope

Meets R3, R4, R5 and R6. R1 and R2 belong to the backend; this page depends on them through the API below.

Open question (trimming): the page trims leading and trailing spaces from the field and sends the trimmed name, so
`  Ada  ` gives `Hello, Ada!`. The backend limit of 50 then applies to the trimmed name as sent. The backend need not
trim.

## Design

**API the page calls** (the backend must provide exactly this):

- `GET {api}/greet?name=<name>`, with the name URL-encoded by `encodeURIComponent`.
- `200` with `{"greeting": "Hello, Ada!"}`.
- `400` with `{"error": "<message>"}`, for a name over 50 characters. The message says the name is too long (at most
  50 characters).

**`src/view.js`** adds pure functions, each returning an HTML string and escaping every value with `escape()`:

- `greetForm()`: a `<form id="greet-form">` with a labelled `<input id="name" name="name">`, a `<button type="submit">Greet</button>`, and an empty `<p id="greeting" role="status"></p>`.
- `greetMessage(result)`: `result` is one of
  - `{greeting: string}` gives `<p class="greeting">…</p>`;
  - `{error: string}` gives `<p class="error">…</p>`;
  - `{needName: true}` gives `<p class="error">Please enter a name.</p>`.

**`src/greet.js`** (new, no DOM access), exports `async greet(api, rawName, fetchFn = fetch)`:

1. `name = rawName.trim()`. If it is empty, return `{needName: true}` and do not call `fetchFn`.
2. Otherwise call `fetchFn(`${api}/greet?name=${encodeURIComponent(name)}`)` and read the JSON body.
3. If the response is ok and has a `greeting`, return `{greeting}`. Otherwise return `{error: body.error}`.

**`src/main.js`** keeps the health check, renders `greetForm()`, and on submit (`preventDefault`) sets
`#greeting`'s `outerHTML` or `innerHTML` to `greetMessage(await greet(api, input.value))`. The result is only ever
put on the page through `greetMessage`, never by concatenating raw text.

## Acceptance checks

Tests in `tests/greet.test.js` and `tests/view.test.js`, using `node:test`, with a fake `fetchFn`.

- R3.1: `greetForm()` contains an `<input` named `name` and a `<button`.
- R3.2: `greet("http://x", "Ada", fake)` calls the fake once with `http://x/greet?name=Ada`. The fake returns `200 {greeting: "Hello, Ada!"}`, and the result is `{greeting: "Hello, Ada!"}`.
- R3.3: `greetMessage({greeting: "Hello, Ada!"})` contains `Hello, Ada!`.
- R3.4: `greet("http://x", "  Ada  ", fake)` calls the fake with `name=Ada`.
- R4.1: `greet(api, "", fake)` returns `{needName: true}` and the fake is not called.
- R4.2: `greet(api, "   ", fake)` returns `{needName: true}` and the fake is not called.
- R4.3: `greetMessage({needName: true})` contains a message asking for a name.
- R5.1: the fake returns `400 {error: "Name is too long (at most 50 characters)."}`, and `greet` returns `{error: "Name is too long (at most 50 characters)."}`.
- R5.2: `greetMessage({error: "Name is too long (at most 50 characters)."})` contains that message and no `class="greeting"`.
- R6.1: `greetMessage({greeting: "Hello, <b>Ada</b>!"})` contains `&lt;b&gt;Ada&lt;/b&gt;` and no `<b>`.
- R6.2: `greetMessage({error: "<img src=x>"})` contains `&lt;img src=x&gt;` and no `<img`.
- R6.3: `greet(api, "<b>Ada</b>", fake)` calls the fake with the name URL-encoded (`%3Cb%3EAda%3C%2Fb%3E`).

## Not in this spec

- The backend's `/greet` route, its greeting text and its 50-character check (R1, R2).
- Handling for an unreachable backend or a non-JSON reply beyond the cases above.
- Styling, history, or remembering names.
